# Vulpix
Games launcher for windows and linux

Our app is designed for gamers and Linux users, who can use it to run games. The app supports Proton (via the umu-launcher). Vulpix will also feature user accounts and chat functions.

Expected entities: Application, Collection (application folder), User, Session (access token), Friendship, PlaySession (in-game time, etc.), Chat, Message

Windows: login, user profile, user’s friends, user’s games,
